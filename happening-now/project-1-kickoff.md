Before session one on **Tuesday, Sep 29**, add yourself to the [members page](/members) by opening a pull request. It takes about 20 minutes. [The contributing guide](https://github.com/eliboug/catalyst-fall26/blob/main/CONTRIBUTING.md) walks you through each step.

- [ ] Set up a GitHub account, Git and Cursor
- [ ] Fork the repo, clone your fork and make a branch
- [ ] Add `members/<netid>.json` and your photo, `members/<netid>.jpg`
- [ ] Commit, push and open the pull request
- [ ] Wait for the green check, then star the repo once a lead merges it

Your profile is public, so only add what you're happy to share. Stuck? Ask in the group chat and paste the error.
