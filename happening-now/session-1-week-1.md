#### 1. Learn Git (about 45 min)

- [ ] Watch [Git Explained in 100 Seconds](https://www.youtube.com/watch?v=hwP7WQkmECE) (Fireship, under 2 min) for a quick overview
- [ ] Play [Learn Git Branching](https://learngitbranching.js.org/?locale=en_US):
  - **Main** tab: *Introduction Sequence*, (commits, branches, merging)
  - **Remote** tab: *Push & Pull -- Git Remotes!*, (clone, fetch, pull, push, and what to do when your push gets rejected)

#### 2. Watch the HTML basics videos (about 35 min)

- [ ] [HTML & CSS Crash Course #2: HTML Basics](https://www.youtube.com/watch?v=mbeT8mpmtHA) (Net Ninja, 20 min)
- [ ] [HTML & CSS Crash Course #6: HTML5 Semantics](https://www.youtube.com/watch?v=kGW8Al_cga4) (Net Ninja, 14 min)

As you watch, look for these, since we'll use them in Workshop 2:

- Tags and attributes
- Headings, paragraphs, links and images
- Lists
- `<header>`, `<nav>`, `<section>` and `<footer>`

If you already know HTML, you can skip the videos.
