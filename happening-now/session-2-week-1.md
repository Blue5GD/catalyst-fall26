#### Workshop 2 recap

In **Workshop 2** we turned our paper sketches into real sites with [Astro](https://docs.astro.build/en/install-and-setup/) and put them live on GitHub Pages. Here's what we covered:

- **Why Astro:** it's HTML first, so you can reuse pieces like your nav across every page, and it builds to static files that GitHub Pages can host for free
- **Setup:** installing Node.js, running `npm create astro@latest`, and starting the dev server with `npm run dev`
- **Components and layouts:** one `.astro` file for each box in your sketch, plus a `BaseLayout` that every page shares
- **Projects as data:** keeping your projects in a list and rendering a `ProjectCard` for each one with props
- **Styling:** scoped styles, global colors and fonts, and a media query for phones
- **Deploying:** setting `site` in `astro.config.mjs`, adding the GitHub Actions workflow, and pushing to go live

Missed it, or want to go over a step again? [The Workshop 2 slides](https://docs.google.com/presentation/d/1Vid4g9Tsp66a7-vrICcc4q80Gp1FgTHTNIuNrRfBF4Y/edit?slide=id.p1#slide=id.p1) walk through each part.
